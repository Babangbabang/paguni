# Changelog

## [0.0.2] - 2026-05-30

### Added
- Two-way sync (original ↔ page editor)
- 7+ comment formats: HTML, JS/CSS/PHP, Multiline, Plain, Python/Ruby, XML/ASP, SQL
- Format icons in Page Explorer
- Automatic format detection

### Changed
- Page editors now show only content within markers
- Faster sync (300ms debounce)
- Better marker detection

### Fixed
- External content no longer deleted during sync
- Page positions no longer shift
- Fixed infinite sync loop
- Fixed HTML/JS comment detection

### Removed
- Close All Page Editors button

---

## [0.0.1] - 2026-05-19

### Added
- Named pages support (use any name, not just numbers)
- Real-time auto-sync to original file
- Page Explorer in sidebar
- Keyboard shortcuts for creating pages
- Multiple comment format support
- Quick Pick page list
- Status bar sync indicator
